MiniRDP Client

A clean, high-performance tabbed Remote Desktop client for power users.

Why MiniRDP

Standard Remote Desktop windows get messy fast when you manage multiple lab or server environments. MiniRDP packages sessions into a clean, modern tabbed interface with zero bloat.

  • Tabbed Sessions & Multi-Window: Run multiple remote connections side-by-side or drag across displays without recreating controls.
  • Per-Monitor V2 Mixed DPI: Crisp rendering and correctly scaled menus whether you're docked, on 4K, or mixing high-DPI displays.
  • Smart Per-Tab Anti-Idle: Configurable, non-intrusive keep-alive that works even when tabs are backgrounded or hidden in the system tray.
  • Quick Switcher (Ctrl+K): Instantly search and jump across active sessions and saved profiles by name, account, or IP.
  • DPAPI Credential Security: Saved credentials are encrypted using Windows DPAPI tied to your local user account—passwords are never saved in plaintext.
